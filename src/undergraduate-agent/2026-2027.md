# 2026–2027 学年目标与规划

## 学年目标

用两个学期完成 [CourseShelf](product.md) 软件的全部开发。CourseShelf 是一个帮助学生整理课程材料、记录学习进度，并支持AI 学习辅助的本地学习工具。具体设计理念和功能见 [CourseShelf 产品需求说明书](product.md)。在过程中掌握一套可迁移的 AI 应用开发能力：能读懂和修改 Python，能设计本地数据模型，能调用 LLM，能让 Agent 使用受控工具，能测试、调试并解释自己的系统。

注：不限制只能开发CourseShelf软件，可以自己提出并开发一个AI相关的应用。
