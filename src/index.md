# 本科生智能体开发

本站面向本科生，使用 AI 编程工具学习并开发真实的智能体产品。总体目标是：能独立做出一个小型智能体，它面向一个具体学习或研究场景，能够调用大模型及相关工具解决实际问题。

当前发布 **[2026–2027 学年目标与规划](undergraduate-agent/2026-2027.md)**。本学年以两周为一个迭代周期，第一学期完成一个软件成果，第二学期增强材料理解、语义检索和 Agent 能力。
