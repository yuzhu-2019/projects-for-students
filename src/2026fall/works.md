# 学习成果

一份成果用来展示你的 **Shelf** 做到了什么：哪一套起步书架、一次 `ask` 或 `brief`、核对与失败、别人如何运行。四块都写上，才算完成。第 8 期集中展示，也可以提前登记。产品说明见 [Shelf](product.md)。

## 要包含的四块

1. **场景。** 哪一套起步书架（学生、科研、工程或组会），帮谁解决什么问题。
2. **一次运行。** 写清调用了哪个工具、返回了什么、最后一句话依据的是哪一次返回或哪一条清单条目。
3. **核对。** 至少一条你事先知道答案的测试，以及一条失败例子和它错在的那一步。
4. **怎么运行。** 在你或同学的电脑上能按说明跑起来。一个 Python 入口，或不超过一页的操作说明。

代码放在你自己的目录里。本页登记说明；若作品有可访问的地址，把链接写在说明里。

## 展区

下面三则是版式示例。换成真实作业时，删去「版式占位」，按同样的小标题填写。

### 量子学习资料整合

版式占位，对应第 4–5 期。

把课程笔记、教程链接和自写速查收成统一条目。提问后先检索，回答里必须标出来源（路径、标签或条目 id）。

| 项目 | 内容 |
| --- | --- |
| 场景 | 复习某算法时快速定位自己的笔记与外链 |
| 运行 | 待补：问题、命中条目、最终回答 |
| 核对 | 待补：一条必中，一条未收录 |
| 运行方式 | 待补：文件位置或操作说明 |

### 科研进展追踪

版式占位，对应第 6 期。

维护方向与关键词清单，定期对比「上次检查」快照，输出增量摘要；摘要每一句能指回条目或 URL。

| 项目 | 内容 |
| --- | --- |
| 场景 | 跟踪例如量子纠错、中性原子等方向的预印本与综述 |
| 运行 | 待补：检查日期、新增条目、摘要 |
| 核对 | 待补：手工已知的新条目是否被检出 |
| 运行方式 | 待补 |

### 专用智能体总览

版式占位，对应第 7–8 期。

同一入口处理「查资料」与「看进展」两类任务；说明不允许做什么（例如不代替读论文、不编造未收录摘要）。

| 项目 | 内容 |
| --- | --- |
| 场景 | 个人日常学习与调研工作流 |
| 运行 | 待补：两类任务各一次 |
| 核对 | 待补：整合与追踪各一条测试 |
| 运行方式 | 待补 |

## 怎么登记

第 7 期原型跑通后，把说明交给负责教师，由教师贴进本页。自己修改时，复制上面任意一则的标题和表格，换成真实内容。
